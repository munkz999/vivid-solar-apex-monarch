# Bag Chart

Yardage chart for your golf bag. Vite + React.

## Basic vs Pro

**Basic (free):** Chart, Bag, and Card.

**Pro:** Round (this-round conditions) and Fit (log shots / swing speed). One-time unlock — Chart, Bag, and Card stay free.

Unlock is stored locally (`bagchart.pro`) until App Store IAP is wired. Price is not set yet.

Tap **Fit** or **Round** while locked to see the paywall. Five taps on the header flag icon toggles Pro on/off for demos.
